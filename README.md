# java-calculator-precourse

### 🧮 입력한 문자열에서 숫자를 추출하여 더하는 계산기

#### = 기능 목록 =

1. 사용자 입력 받기

- `Console.readLine()`을 사용하여 한 줄의 입력을 받는다.
- 입력 안내 문구: `덧셈할 문자열을 입력해 주세요.`

2. 빈 입력과 공백 입력 처리

- 빈 문자열 `""` 이나 공백이 입력되면 결과로 `0`을 출력한다.

3. 기본 구분자 처리

- 기본 구분자는 쉼표(`,`)와 콜론(`:`)이다.

4. 커스텀 구분자 처리

- 커스텀 구분자는 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 문자이다.

5. 숫자 파싱 및 검증

- 구분자로 분리된 문자열을 `double`형으로 변환한다.
- 입력된 숫자는 양수(>0)여야 한다.

6. 합 계산

- 숫자를 더해 합을 구한다.

7. 출력

- 숫자의 합을 `결과 : X` 형태로 출력한다.

8. 예외 처리 및 종료

- 잘못된 값이 입력되면 `IllegalArgumentException`을 발생시킨 후 애플리케이션이 종료된다.
    - 0과 음수 또는 숫자가 아닌 값이 숫자 자리에 들어온 경우
    - 구분자가 연속적으로 입력된 경우
    - 커스텀 구분자가 두 글자 이상인 경우
    - 커스텀 구분자가 숫자인 경우

**입출력 예시** <br>
덧셈할 문자열을 입력해 주세요. <br>
1,2:3 <br>
결과 : 6 <br>

덧셈할 문자열을 입력해 주세요. <br>
//;\n1;2;3 <br>
결과 : 6 <br>
