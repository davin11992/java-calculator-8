# java-calculator-precourse

### 🧮 입력한 문자열에서 숫자를 추출하여 더하는 계산기

- 입력하는 숫자 값은 **양의 정수**로 제한하였습니다.

    - 커스텀 구분자가 `.`(마침표)일 경우, `0.5`와 같은 소수 입력과 혼동될 수 있기 때문입니다.

- 커스텀 구분자는 **한 글자의 문자(공백 포함, 숫자 제외)** 로만 허용하였습니다.
- 기본 구분자(`,`, `:`)와 커스텀 구분자를 **혼용**할 수 있습니다.

<br>

#### 🧩 기능 목록

1. 사용자 입력 받기 (InputView)

- `Console.readLine()`을 사용하여 입력을 한 줄 단위로 받는다.
- 입력 안내 문구: `덧셈할 문자열을 입력해 주세요.`

  <br>

2. 입력 검증 (InputValidator)

- 입력이 `null`, 빈 문자열 `""`, 공백만 포함된 경우 `0`을 반환한다. <br>

 <br>

3. 문자열 파싱 (NumberParser)

- 입력 문자열을 기본 구분자(`,`,`:`) 또는 커스텀 구분자를 기준으로 분리한다.
- 커스텀 구분자는 `//`와 `\n` 사이에 위치하는 문자이다.

<br>

4. 커스텀 구분자 처리 (CustomDelimiterHandler)

- 기본 구분자(`,`,`:`)에 커스텀 구분자를 추가하여 최종 정규식 구분자 패턴을 생성한다.
- 다음을 위반하면 `IllegalArgumentException`을 발생시킨다.
    - 커스텀 구분자가 두 글자 이상인 경우
    - 커스텀 구분자가 숫자인 경우

  <br>

5. 숫자 검증 (NumberValidator)

- 구분자로 분리된 문자열을 검사한다.
- 다음을 위반하면 `IllegalArgumentException`을 발생시킨다.
    - 구분자 뒤에 숫자를 입력하지 않은 경우
    - 숫자와 구분자 사이에 공백이 존재하는 경우
    - 0 또는 음수를 입력한 경우
    - 숫자가 아닌 값을 입력한 경우

 <br>

6. 합 계산 (Calculator)

- 검증된 문자열을 정수로 변환하여 합을 구하고 반환한다.

 <br>

7. 출력 (OutputView)

- 숫자의 합을 `결과 : X` 형태로 출력한다.

 <br>

8. 예외 처리 및 종료

- 잘못된 값이 입력되면 `IllegalArgumentException`을 발생시킨 후 애플리케이션이 종료된다.

 <br>

**💬입출력 예시** <br>

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

```
덧셈할 문자열을 입력해 주세요.
//;\n1;2;3
결과 : 6
```
